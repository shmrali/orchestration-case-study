# Orchestration Case Study

An AI workflow orchestration case study with an interactive Smart Expense Tracker prototype.

## Website

The static website is in `dist/`. Open `dist/index.html` through a local web server. The prototype uses illustrative INR data and stores edits in the browser; it does not connect to bank accounts or require an API key.

## Vercel deployment

- Framework preset: Other
- Root directory: repository root
- Build command: leave empty
- Output directory: `dist`

The case study includes links to web and mobile prototype modes. No backend or Render service is required.
